 *   <li><b>Shortcut:</b> sets the fill of the normal state only; equivalent to {@link anychart.core.arcDiagram.elements.Link#normal}().fill(value).</li>
 *   <li><b>Redraw:</b> takes effect on a chart that is already drawn.</li>
 * </ul>
 * @example anychart.core.arcDiagram.elements.Link.fill_set

/**
 * Getter for the link thickness.
 * @shortDescription Link thickness.
 * @category Interactivity
 * @example anychart.core.arcDiagram.elements.Link.thickness_get
 * @return {(number|Function)} The thickness in the normal state.
 * @since 9.0.0
 */
anychart.core.arcDiagram.elements.Link.prototype.thickness;

/**
 * Setter for the link thickness.
 * @detailed
 * <ul>
 *   <li><b>Default:</b> undefined, so a link's arc width is scaled by weight: between 1 and 8 pixels, proportional to the link's value over the heaviest link's value.</li>
 *   <li><b>Accepted values:</b> a number of pixels, or a function that returns one, called with a context of {value, maxValue, from, to, sourceColor} for this link.</li>
 *   <li><b>Negative:</b> a negative value becomes 0.</li>
 *   <li><b>hovered() / selected():</b> undefined on these states inherits the fully resolved normal() thickness, instead of falling back to the by-weight formula directly.</li>
 *   <li><b>Null:</b> null clears the own value and restores the by-weight default.</li>
 *   <li><b>Shortcut:</b> sets the thickness of the normal state only; equivalent to {@link anychart.core.arcDiagram.elements.Link#normal}().thickness(value).</li>
 *   <li><b>Redraw:</b> takes effect on a chart that is already drawn.</li>
 * </ul>
 * @example anychart.core.arcDiagram.elements.Link.thickness_set
 * @param {(number|Function)=} opt_thickness Thickness to set, in pixels.
 * @return {anychart.core.arcDiagram.elements.Link} Self instance for method chaining.
 * @since 9.0.0
 */
anychart.core.arcDiagram.elements.Link.prototype.thickness;
