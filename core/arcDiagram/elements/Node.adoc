/**
 * Getter for the node width.
 * @shortDescription Node width.
 * @category Interactivity
 * @example anychart.core.arcDiagram.elements.Node.width_get
 * @return {(number|Function)} The width in the normal state.
 * @since 9.0.0
 */
anychart.core.arcDiagram.elements.Node.prototype.width;

/**
 * Setter for the node width.
 * @detailed
 * <ul>
 *   <li><b>Default:</b> undefined, so the chart draws every node at its built-in 20-pixel baseline.</li>
 *   <li><b>Accepted values:</b> a number of pixels, or a function that returns one, called with the node's formula context.</li>
 *   <li><b>Negative:</b> a negative value becomes 0.</li>
 *   <li><b>Null:</b> null clears the own value and restores the default baseline.</li>
 *   <li><b>Weighted sizing:</b> a value set here replaces the weighted size, so every node is drawn at this width and weightedNodes(), minNodeSize() and maxNodeSize() no longer apply; left unset, the 20-pixel baseline is what weighted sizing scales.</li>
 *   <li><b>Shortcut:</b> sets the width of the normal state only; equivalent to {@link anychart.core.arcDiagram.elements.Node#normal}().width(value).</li>
 *   <li><b>Redraw:</b> takes effect on a chart that is already drawn.</li>
 * </ul>
 * See {@link anychart.charts.ArcDiagram#weightedNodes}, {@link anychart.charts.ArcDiagram#minNodeSize} and {@link anychart.charts.ArcDiagram#maxNodeSize} for the weighted sizing this width overrides.
 * @example anychart.core.arcDiagram.elements.Node.width_set
 * @param {(number|Function)=} opt_width Width to set, in pixels.
 * @return {anychart.core.arcDiagram.elements.Node} Self instance for method chaining.
 * @since 9.0.0
 */
anychart.core.arcDiagram.elements.Node.prototype.width;
