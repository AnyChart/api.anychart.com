/**
 * @ignoreDoc
 * Appends new data rows to the series.
 * @detailed
 * <ul>
 *   <li>If boost is active for the series, the new rows are rendered incrementally onto the existing boost canvas.</li>
 *   <li>Otherwise (boost disabled, the series is below its threshold, or its drawer is permanently excluded from boost), the rows are appended the normal way: append, then a full redraw.</li>
 *   <li>Area and spline series fall back to a full redraw even when boost is active.</li>
 * </ul>
 * @param {!Array} newRows Array of data rows in the same format as the series data (e.g. [x, y] pairs for line, [x, y, size] for bubble).
 */
