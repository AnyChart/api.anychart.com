/**
 * Setter for the node corner radius.
 * @detailed <ul>
 *   <li><b>Shortcut:</b> cornerRadius() is a shortcut to normal().cornerRadius(); the hovered and the selected states have their own corner radius.</li>
 *   <li><b>No theme default:</b> a freshly created level reads cornerRadius() back as undefined; the drawn radius falls back to the node type's, then the chart's own un-themed default (4 pixels), until this is set.</li>
 *   <li><b>Clamping:</b> at draw time the radius is clamped to half of the smaller side of the card box, so a radius bigger than the card cannot turn its outline inside out.</li>
 *   <li><b>Function form:</b> a function is also accepted, called once per node with the same context {@link anychart.core.orgChart.Level#fill}'s function form receives; its return value is read as a plain number.</li>
 *   <li><b>Invalid values:</b> a non-numeric value (e.g. a string) is stored as NaN, which the getter reads back as NaN; a NaN radius falls back to the same un-themed default as undefined at draw time. <code>null</code> normalizes to 0.</li>
 *   <li><b>Redraw:</b> takes effect on a chart that is already drawn.</li>
 * </ul>
 * @example anychart.core.orgChart.Level.cornerRadius_set
 * @param {(number|Function)=} opt_radius Corner radius in pixels to set, or a function returning it per node.
 * @return {anychart.core.orgChart.Level} Self instance for method chaining.

 * @detailed <ul>
 *   <li><b>Applies to:</b> the connectors drawn into the cards at this level.</li>
 *   <li><b>Position:</b> the child end of each connector, its tip on the child card's outline; the connector line is shortened by the marker size.</li>
 *   <li><b>Value:</b> an object with the fields <code>enabled</code> (false), <code>type</code> ('circle'), <code>size</code> (6 pixels), <code>fill</code> ('#666'), <code>stroke</code> (none) and <code>orientation</code> ('auto').</li>

 *   <li><b>Replacing:</b> a new object replaces the previous one as a whole - connectorEndMarker({size: 12}) after connectorEndMarker({enabled: true}) drops the <code>enabled</code> field.</li>
 *   <li><b>Priority:</b> the settings are merged field by field: a field set here wins over the same field of the chart's own {@link anychart.charts.OrgChart#connectorEndMarker}, and loses to the same field set directly on the data row; fields not set here come from the chart.</li>
 *   <li><b>No theme default:</b> a freshly created level reads connectorEndMarker() back as undefined; the chart's own {@link anychart.charts.OrgChart#connectorEndMarker} applies until this is set.</li>
 *   <li><b>Function form:</b> a function is also accepted and called once per connector, with <code>this.node</code> set to the connector's child node; the object it returns is read the same way as a literal object.</li>
 *   <li><b>Invalid values:</b> a string, a number, a boolean or <code>null</code> normalizes to null: the getter reads null back and the marker settings of the chart apply.</li>
 *   <li><b>Redraw:</b> takes effect on a chart that is already drawn.</li>
 * </ul>
 * @example anychart.core.orgChart.Level.connectorEndMarker_set
 * @param {(Object|Function|null)=} opt_settings Marker settings, or a function returning them, to set.
 * @return {anychart.core.orgChart.Level} Self instance for method chaining.
