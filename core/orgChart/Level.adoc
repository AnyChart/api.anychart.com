/**
 * Setter for the connector stroke.
 * @detailed <ul>
 *   <li><b>Applies to:</b> the connector drawn into a card at this level.</li>
 *   <li><b>Priority:</b> a stroke set here wins over the node type's and the chart's own {@link anychart.charts.OrgChart#connectorStroke}, and loses to a connector stroke set directly on the data row.</li>
 *   <li><b>No theme default:</b> a freshly created level reads connectorStroke() back as undefined until it is set.</li>
 *   <li><b>Function form:</b> a function is also accepted and called once per connector, with <code>this</code> exposing <code>node</code>/<code>item</code>/<code>data</code> (the connector's lower-endpoint node), <code>level</code>/<code>depth</code>, <code>state</code> and <code>sourceColor</code> (the stroke the tier below this level would otherwise use); its return value goes through the same normalization as a literal stroke.</li>
 *   <li><b>Invalid values:</b> a string that is not a recognized stroke shorthand is kept as-is, unvalidated; an object that cannot be resolved to a stroke normalizes to the plain color 'black'.</li>
 *   <li><b>Redraw:</b> takes effect on a chart that is already drawn.</li>
 * </ul>
 * @example anychart.core.orgChart.Level.connectorStroke_set
 * @param {(anychart.graphics.vector.Stroke|anychart.graphics.vector.ColoredFill|string|null|Function)=} opt_stroke Stroke, or a function returning one, to set.
 * @param {number=} opt_thickness Line thickness.
 * @param {string=} opt_dashpattern Controls the pattern of dashes and gaps used to stroke paths.
 * @param {anychart.graphics.vector.StrokeLineJoin=} opt_lineJoin Line join style.
 * @param {anychart.graphics.vector.StrokeLineCap=} opt_lineCap Line cap style.
 * @return {anychart.core.orgChart.Level} Self instance for method chaining.
 * @since 9.0.0
 */
anychart.core.orgChart.Level.prototype.connectorStroke;

/**

 * @return {(number|Function)} The corner radius.
 * @since 9.0.0
 */
anychart.core.orgChart.Level.prototype.cornerRadius;

/**
 * Setter for the node corner radius.
 * @detailed <ul>
 *   <li><b>Shortcut:</b> cornerRadius() is a shortcut to normal().cornerRadius(); the hovered and the selected states have their own corner radius.</li>
 *   <li><b>No theme default:</b> a freshly created level reads cornerRadius() back as undefined; the drawn radius falls back to the node type's, then the chart's own un-themed default (4 pixels), until this is set.</li>
 *   <li><b>Clamping:</b> at draw time the radius is clamped to half of the smaller side of the card box, so a radius bigger than the card cannot turn its outline inside out.</li>
 *   <li><b>Function form:</b> a function is also accepted, called once per node with the same context {@link anychart.core.orgChart.Level#fill}'s function form receives; its return value is read as a plain number.</li>
 *   <li><b>Invalid values:</b> a non-numeric value (e.g. a string) is stored as NaN, which the getter reads back as NaN; a NaN radius falls back to the same un-themed default as undefined at draw time. <code>null</code> normalizes to 0.</li>
 *   <li><b>Redraw:</b> takes effect on a chart that is already drawn.</li>
 * </ul>
 * @example anychart.core.orgChart.Level.cornerRadius_set
 * @param {(number|Function)=} opt_radius Corner radius in pixels to set, or a function returning it per node.
 * @return {anychart.core.orgChart.Level} Self instance for method chaining.
 * @since 9.0.0
 */
anychart.core.orgChart.Level.prototype.cornerRadius;
