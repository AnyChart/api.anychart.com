/**
 * DataSheet chart class.<br/>
 * A DOM-based interactive data grid with virtual scrolling, column sorting, filtering, cell editing, row selection,
 * grouping/hierarchy and clipboard support.<br/>
 * Unlike the other chart types, DataSheet renders as HTML rather than on a stage and extends
 * {@link anychart.core.VisualBaseWithBounds} directly, so the common chart members - title(), legend(),
 * tooltip(), credits(), animation(), background() - are intentionally not provided.<br/>
 * <b>Note:</b> Use {@link anychart.dataSheet} method to get this chart.<br/>
 * @constructor
 * @extends {anychart.core.VisualBaseWithBounds}
 * @since 9.0.0
 */
anychart.charts.DataSheet;

 * @listing See listing

 *   title: 'My Data Grid'
 * });

 * <ul>
 *   <li><b>orientation</b> {string} - 'landscape' switches the page to landscape; any other value prints portrait.</li>

 *   <li><b>includeFiltered</b> {boolean} - when <b>true</b>, prints every row of the source data in its original order,
 *   ignoring the current filter <i>and</i> the current sorting. When omitted or <b>false</b>, prints the visible filtered and sorted view.</li>
 * </ul>
 * @since 9.0.0
